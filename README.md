# VisionSoul

## 1. 项目简介

VisionSoul 是一个具有视觉感知与动态人格模拟能力的多模态 AI 交互系统。

系统允许用户通过文字和图片与 AI 角色进行交流。AI 能够理解用户上传的图片内容，并结合预设人格生成自然、连贯的对话。

## 2. 核心功能

- 图片上传与展示
- 多模态视觉理解
- 人格化自然对话
- 模拟情绪表达
- 用户经历与偏好记忆

## 3. 技术架构

- 前端：React + Tailwind CSS
- 后端：Python + FastAPI
- 数据库：SQLite
- AI 能力：多模态大模型 API
- 版本管理：Git

## 4. 项目目录

- frontend：前端代码
- backend：后端代码
- database：数据库
- prompts：AI 提示词记录
- docs：项目技术文档
- tests：测试文件

## 5. 开发目标

构建一个能够理解用户视觉分享、保持稳定人格并具备基础记忆能力的 AI 交互应用。

本项目采用迭代开发方式，持续记录重要 Prompt、代码修改和 Git 提交历史。
