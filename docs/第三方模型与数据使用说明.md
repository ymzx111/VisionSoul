## 组件与项目实现的边界

没有从零训练或微调上述模型，不把第三方模型称作自主训练成果，也不把外部公开视频称作自摄。项目实现包括安全上传、抽帧与高清候选选择、共同时间轴、音画候选与引用校验、对白校对、角色与记忆管理、缓存和交互界面。候选时间接近不代表内容已验证；相对声音线索不是情绪识别。

页面顶部保留DeepSeek配置状态，图片结果保留模型标识；统一页脚补齐本机语音组件和数据流说明，不新增模型请求、上传步骤或弹窗确认。

- 本地安装脚本`backend/tools/setup_audio_model.py`固定权重revision `536b0662742c02347bc0e980a01041f333bce120`，并校验model.bin SHA256；下载的模型说明保存在被Git忽略的权重目录。
- 公开视频来源和许可另见`datasets/video_eval/ATTRIBUTION.md`。分发组件或素材时保留各自适用的许可证和署名；此页不替代原许可。

标注以当前实际实现为准，后续更换模型、云端语音服务或数据路径时应同步更新。模型回复、自动转写和时间估计均可能出错，关键名称和时间需要回看、回听。

## Python 隔离试跑组件（2026-11-12）

本机使用 [Wasmtime](https://pypi.org/project/wasmtime/50.0.1/) 和 [CPython 3.13.17 WASI 第三方发行构建](https://github.com/brettcannon/cpython-wasi-build/releases/tag/v3.13.17) 执行源码。这两项是运行时组件。VisionSoul 实现验收请求、文件授权、沙箱启动与限制、结果校验和源码归档。安装校验见 [安装脚本](../tools/install_python_sandbox.py)。

样例输入、预期输出和用户选取的测试文件仅在本机验收。普通 Python 异常触发修复时，最多一次 DeepSeek 请求发送原任务、生成源码和异常类型，产生独立用量。详见 [P045](../prompts/P045_Python隔离试跑与自动修复.md)。
