# VisionSoul 音画实拍验收清单

当前范围：H.264 MP4、最长30秒；每1秒采样并补末帧，最多31次；显式细看最多4张高清。对白由本机模型识别，画面和转写文字交给DeepSeek理解。以下实拍项目待使用者验收，不将自动化或公开示例测试当成实拍准确率。

## 建议准备的素材

| 场景 | 录制方式 | 重点观察 |
|---|---|---|
| 边拍边说 | 先后拍两个物体，并说出正在介绍哪个 | 是否区分画面事实与讲话内容，时间引用能否回听 |
| 先说后展示 | 约10秒提到某物，11秒才把镜头转过去 | 是否允许时间容差，而不是只匹配同一秒 |
| 内容不一致 | 画面拍书本，讲话却介绍湖水 | 是否提示缺少对应画面或内容不一致，避免硬配 |
| 无对白 | 录一段静音或只有环境声的场景 | 是否明确无可靠对白，仍能分析画面；不能编造讲话 |
| 专有名词与数字 | 讲话包含地名、名称或数量 | 是否方便回听和校对；后续追问是否使用校对内容 |

## 每段视频的检查顺序

1. 上传后检查采样点覆盖首尾、对白起止时间及文字；不需要立即分析。
2. 如有错字，点击“校对白”，对照原文修改文字或起止秒数。保存只写本机，不调用API；原始转写保留。
3. 发送配文进行一次分析，询问主要内容；记下等待时间与页面显示的token。
4. 再问“为什么这样判断？请给出具体时间依据”。检查引用是否来自实际对白，并能点击回放。
5. 修改一处对白，再普通追问：应采用校对白；旧综合报告标待更新，过期关联不应继续显示为新依据。
6. 如需重做完整音画分析，主动点击“细看并比对”。这一步会产生API用量，不为测试反复点击。
7. 刷新页面，确认话题、校对内容、原始转写和待更新状态仍可恢复。

时间窗口是句子区间前后1.5秒优先、3秒补充；它只是候选范围，不保证内容一定相关。近似去重只影响高清名额，不能据此宣称识别了全部短暂动作。
