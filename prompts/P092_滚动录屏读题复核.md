# P092 滚动录屏读题复核

> 优化视频分析显示，这次我采用电脑录制，画面非常清晰，我能通过收集的图片看到”题目要求“和”输出格式“但它还是让我返回清晰图片，检查为何会出现这个情况，问题在哪，并对其进行优化修复

- 2026-11-15，Codex。检查本地 Python 词频题录屏话题，记录识别出第 11、14 号帧的区块，但高清帧列表为空。模型用“看不全、请补充……高清截图”的自然语言收尾，旧逻辑未触发高清复核。
- 扩展复核触发语句。定位到题目要求和输出区时，按两个区块的原片时间选同一段，沿用半秒补抽与最多 4 张高清的预算。模型跨帧核对筛选、同频排序和工具限制。
- 提示保留可读的明确正文规则与示例排版。若样例数值违反明确限制，用真实数据按正文计算并说明差异。两处正文规则相冲突时仍请用户确认。
- 修改 `backend/app/services/video_reading.py`、`backend/app/services/videos.py`、`tests/test_video_reading.py` 与开发便签。模型沿用项目配置；回归使用模拟响应。
- 视频 111 项回归通过。用同一段录屏和原低清回复离线回放，复核区间为 11.012–16.012 秒，选中 11.512、12.958、14.012、16.004 秒四张原片高清图，覆盖题目要求、输出示例及约束。验证两次请求后交付的分流路径，未调用付费模型。
