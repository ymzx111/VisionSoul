## 4. 本轮采用的实现约束

1. 不重建项目或 Git，不修改历史记录。
2. 本轮只完成独立的图片上传模块，不调用模型 API、不需要 API Key。
3. 支持 JPEG、PNG、WebP 静态图片，大小默认最多 10 MiB，总像素最多 2000 万，单边最多 8192 像素。
4. 在 multipart 解析前限制完整请求体，并兼容分块传输；文件读取也有独立上限。
5. 使用 Pillow 解码及校验实际内容，拒绝空文件、损坏文件、不支持的格式和动图。
6. 纠正 EXIF 方向后重新编码，移除元数据和尾随非像素内容；随机命名且不信任上传文件名。
7. 响应仅返回图片标识、预览相对 URL、媒体类型、保存后大小及宽高，不暴露磁盘路径。
8. 上传图片不进入 Git；当前没有账号，图片预览用于本机开发。
