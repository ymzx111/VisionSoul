# P042 生成代码保存到本机

2026-11-12。Codex 实现 Python 命令行工具，使用标准库。

> 请帮我写一段 Python 脚本，实现“读取 AI 生成的代码并自动在本地创建文件”的功能。
>
> 输入一段包含 [文件名: xxx.c] 和 Markdown 代码块格式的文本。用正则提取文件名和纯代码内容，在当前目录创建 workspace，写入对应文件，返回包含绝对路径的成功提示。提供完整、带注释的 Python 代码。

`tools/save_generated_code.py` 从 UTF-8 文件或标准输入读取一份带文件名声明的回复。保留缩进和空行，校验文件名与语言扩展名，在当前目录的 `workspace` 下创建文件。重复文件名返回错误并保留旧文件。本机输出目录已加入 `.gitignore`。

在项目根目录执行：

~~~powershell
.\.venv\Scripts\python.exe .\tools\save_generated_code.py .\ai_reply.txt
~~~

临时目录中验证了 C 文件、Python 中文文件名与缩进、CRLF 和 BOM、较长 Markdown 围栏、同名文件保护以及无效路径或格式的拒绝。此轮完成命令行保存，网页自动传递回复和编译运行待后续验收。
