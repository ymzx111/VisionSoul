# P012：统一小灵人格与自然回应

## 用户实际指令

> 继续接下去的任务，接下去应该是继续优化人物性格表现吧。或者你有别的任务，告诉我一声，然后我们进行。

日期：2026-11-08。工具：Codex 桌面应用；具体执行模型版本未单独核验。沿用已确认的“活泼俏皮，轻度幽默”，不重新询问已决定的风格。

从 master 的 ad8eee8 继续；P011 前端上传校验、README 和 P011 记录仍未提交，全部保留。本轮范围是提示组织与性格表达，不增加视频追问、长期记忆、独立情绪系统或界面功能。

## 决策与实际提示

- 检查发现视频和聊天分别写了身份/风格，后续容易漂移。新增 `backend/app/prompts/persona.md` 作为共用性格，`core/persona.py` 读取为 PERSONA_CORE。
- PERSONA_PROMPT = 共用性格＋`companion.md`，继续由聊天和单图理解使用；VIDEO_PROMPT = 共用性格＋`video.md`。
- 共用性格为 187 个字符；当前组合视频提示 791 字符，只加入一次。字符数不是 token 数，不据此宣称费用一定下降。
- 表达特点：注意小细节、克制的小比喻、有自己的看法；不逢事夸奖、不硬说治愈浪漫、不用固定口头禅、不每次反问；严肃或难过语境收起玩笑。
- 视频 summary 仍负责事实，reply 围绕一个有依据的细节说一两句，少用报告腔，不改写 summary。去掉原先带固定俏皮句子的 JSON 示例，改为只说明字段结构，减少照抄示例的倾向。
- 事实依据、AI 身份、模拟情绪、未知记忆和用户关系边界保留。用户需要技术解答时仍应直接完成任务，不能为了风格牺牲内容。
- 完整运行提示分别保存在上述三个 Markdown 文件；本次视频 user 文本、图片精度、采样规则与输出预算未改。用户消息只有普通 user 角色，无法覆盖固定 system 人格。
- 人格规则版本改为 xiaoling-v2。历史聊天文字和已完成消息请求缓存不改写。

## 成本与缓存

视频依然只发一次请求同时生成观察、摘要和小灵回应，没有新增“润色轮次”、依赖或模型切换。共用性格通过已有 VIDEO_PROMPT 参与缓存指纹；人格更新后旧缓存不冒充新风格，旧结果保留，用户手动分析时才可能产生新用量。没有自动重算用户的视频。

开发验证明确限制最多 3 次真实调用，按顺序完成，没有自动重试。文字样例直接使用模型客户端，不写入真实聊天数据库；视频只使用本聊天自制插画样例，不使用用户上传的视频进行额外付费分析。

### 真实样例 A：小成果，462 token

实际 user 消息：

> 我今天终于把三行 Python 代码跑通了，花了两个小时。请用两句话回应。

实际回复：

> 两小时换三行跑通，这买卖不算亏——排错的时间大多花在找那一个不起眼的错误上。能自己一点点排查到通，这份耐心比代码本身值钱。

用量：输入 420、输出 42，总计 462 token。风格评审：有轻巧比喻、回应具体投入，没有用统一口头禅或反问结束。用户没有明确说独立排错，“自己一点点排查”仍带少量推断，不能作为精确事实验证。

### 真实样例 B：失落，459 token

实际 user 消息：

> 今天考试没考好，很烦。你先别讲笑话，也先别给学习计划。请用两句话回应。

实际回复：

> 考砸了确实挺堵心的，这会儿烦就先烦着，不用急着消化。我在这儿听着，你想说说哪科最让你不甘心就说。

用量：输入 427、输出 32，总计 459 token。没有讲笑话或擅自给计划，但把“没考好”升级为“考砸”，措辞偏重。依据这个实际弱点，在最终 companion.md 中补充“不替用户加重负面措辞或情绪程度”；没有超过预定三次调用预算另行重测，因此该最后一句规则还需后续真实体验确认。

### 真实样例 C：插画月亮/水面视频，2007 token

视频是本聊天生成的 12 秒无声插画，均匀采样 30 次、像素完全相同相邻画面合并后保留 6 张。仍使用现有 VideoService，模型一次生成完整 JSON。

实际小灵回应：

> 那颗圆月圆得太标准，像卡通片场借来的道具；后面水面的横线倒像有人偷偷拿尺子画的波纹。

实际摘要：

> 前半段是深蓝夜空、亮圆盘与山脊剪影，后段切换成层叠山峰和带波线的水面画面。

关键词：夜空/亮圆/星点，山峦/水面/波线。用量：输入 1837、输出 170，总计 2007 token。观察评审：reply 有具体视觉细节和轻微幽默，没有重复列举全部关键词，也没有固定反问。此素材本来就是插画，不能把对其画风的调侃当作所有真实视频的通用语气。

三次真实调用合计 2928 token。不把开发样例的费用当成所有视频的固定费用，也不以这些少量例子宣称人格全面稳定。
