# P015：从其他 AI 粘贴导入小灵人格卡

日期：2026-11-08

## 1. 用户实际 Prompt

> 我想通过一种别的方法，就是我去找一个ai模型，通过对话，确认好人物性格，设定好背景等等东西，然后我就可以一键复制导入到小灵的角色卡，从而创建好小灵这个角色。不过我目前没有看到可以一键导入到小灵“人格卡”的界面，请你帮我添加一个。

工具：Codex 桌面端直接修改现有项目，浏览器验证使用 computer-use 工具。未新增依赖、数据库表或后端 API，未发起真实模型调用。

## 2. 实现

人格卡标题右侧新增“粘贴导入”，打开可关闭的原生模态对话框，包含：

- “复制给其他 AI 的提示词”按钮，以及可展开、手动复制的完整模板。
- JSON 粘贴区、逐项中文预览、具体错误说明。
- “导入并保存草稿”按钮，仍由主卡片“保存并生效”决定是否应用于正式聊天。

实际提供给用户复制的完整提示词定义在 `frontend/src/role-import.mjs` 的 `ROLE_IMPORT_PROMPT`，包括逐步讨论、一问一答、只导出 JSON、固定小灵名字/AI 伙伴身份和各字段长度约定。示例为中文字段，未引入另一套模型转换或付费润色流程。

本地校验支持中文和英文平铺字段、可选 json 代码框、`profile` 包装对象（可附带不导入的 reply）。按现有后端长度上限校验字符串，拒绝未知字段、中英文别名冲突、其他角色名、空必填内容和非字符串；只提供名字不足以导入。最大输入 12000 个 UTF-16 单元，超长粘贴提示只复制最终 JSON。

允许部分字段导入：在当前页面草稿上合并，只覆盖预览中列出的字段，其余字段保留。保存通过既有 `PUT /api/roles/xiaoling/draft` 完成，使用当前版本号避免覆盖其他窗口已经保存的内容。失败不清空粘贴文字或当前草稿。成功后清除旧角色预览，提示“已保存草稿，尚未生效”。不处理用户记忆，不自动发布。
