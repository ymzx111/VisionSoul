## 3. 实现

- 新操作页 `/app/`：左侧图片，右侧提问与结果，减少来回展开和滚动。
- 单张图片自动上传，获得的 image_id 自动用于后续分析，无需用户抄写。
- 图片预览使用当前所选文件；上传返回的编号和宽高用于确认同一张图片已就绪。
- 只有点击“开始分析”才请求 `/api/vision/analyze`；上传不会触发模型。
- 多选只在本地显示缩略图和移除按钮，提示“目前只能分析单个图像”，分析按钮禁用；不请求上传或模型接口。
- 从多张移除到一张时，仅自动上传剩下的一张，再允许分析。
- 选择更新时忽略过期上传结果；分析时锁定图片与问题，并阻止重复调用。
- 有上传、配置、等待、错误、真实回复和用量状态；不使用虚假成功回复。
- 保留现有 API 和中文文档，文档顶部添加工作台入口。
- React 19.3.1、Vite 8.3.6、Tailwind CSS 4.3.5；通过 FastAPI 同源提供构建产物，无需把密钥放入前端。
- 本版不实现多图理解、连续会话、人格和记忆；不扩展模型 API。
