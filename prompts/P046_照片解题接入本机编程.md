## 修改

- 照片入口原先缺少源码交付提示与本机 IDE 标记。工作解析的单图话题现与视频共用源码声明、保存、沙箱与 IDE 流程。留空提交时，照片中的完整编程题可以按题意交付源码。普通图片照常说明，题目条件缺失时请用户确认。
- 后端修改聊天路由、提示构建与 IDE 模块说明。沿用同源回环、工作空间和完整回复校验。前端修改媒体发送流程、输入提示和 Python 验收样例入口。
- 修改前端聊天空间测试，并在后端聊天测试中用实际 WASI 检查样例输出、源码归档与临时文件清理。用模拟模型和 IDE 启动调用验证同源照片触发 IDE，以及普通图片、角色、重放与外部来源均不触发。未产生模型用量。
- 联调发现旧 WASI 安装目录保留了临时目录的受限权限。安装器改用继承权限的同级暂存目录；本机保留原目录备份，从已校验的安装包重装。运行时不可读时网页显示原因，试跑停止。
- 本机用临时示例单独验证 Windows Python IDLE 编辑窗口确实打开，随后关闭并清理。新版工作台已重启并验证加载。
