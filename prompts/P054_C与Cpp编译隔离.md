# P054 C/C++ 编译隔离

> 先把这个C/C++编译隔离做好

- 日期 2026-11-14。使用 Codex、本地 Node.js 和 Wasmtime。
- Zig 与原生 Clang 在本机 AppContainer 中未通过兼容验证。改用 [YoWASP 的 Clang/LLD WebAssembly 组件](https://github.com/YoWASP/clang)（22.0.0-git20542-10），在进程内的虚拟文件系统编译。项目自行实现输入、产物和诊断传递。
- Node 子进程启用权限模式，仅为可信启动器及固定编译资产授予文件读取权限。编译器的虚拟文件系统只接收当前源码和标准库，未挂载宿主目录。启动前逐文件校验 SHA-256，限制 45 秒、最多 8 MiB Wasm 和 4 KiB 诊断。
- 本地授权文件只提供给 Wasmtime 运行阶段。编译器或隔离环境不可用停止自动验收。同一轮的多组验收仍共用一份临时 Wasm。当前面向单文件标准库控制台题，C++ 异常处理关闭。
- 测试使用本机 C/C++ 样例、临时宿主头文件及两条静音视频回归。模型回归使用模拟回复。
