## 2. 实际用户指令（原文）

> 能帮我把里面的这些各项东西，调为中文吗

上下文为用户正在访问的本机 `/docs` 接口文档。

## 3. 范围和实现

- 把 Swagger 页面中的试用、发送、取消、重置、选择图片、响应栏目、示例和数据结构等显示文字补充为中文。
- 添加中文页面标题、语言标记和“上传图片 → 复制编号 → 图片理解”的操作提示。
- 增加字段的中文标题和说明，包括图片编号、文件大小、宽高、提问、回复、模型配置和 token 用量。
- 增加首页、健康检查的显式响应结构，以及各主要错误码的中文说明。
- 本地中文补充脚本通过观察页面变化更新动态界面；不改写代码块、请求编辑框或原始 JSON 字段。
- 文件选择器的中文按钮触发原生文件选择事件，保留 Swagger 的上传状态管理。
- 请求路径、方法、字段名称及接口返回内容的含义不变；原有上传和模型功能不扩展。
- Swagger 核心资源仍采用原 CDN，不下载或改写第三方库。

## 4. 修改文件

- `backend/app/main.py`：注册中文文档路由和本地资源；首页响应中文说明。
- `backend/app/api/routes/docs.py`：中文 `/docs` HTML。
- `backend/app/docs_assets/zh-cn.js`：动态界面中文显示和中文文件选择器。
- `backend/app/docs_assets/zh-cn.css`：中文必填标记、操作提示和文件选择按钮样式。
- `backend/app/api/routes/health.py`：健康状态字段说明。
- `backend/app/api/routes/images.py`：上传、预览参数及响应字段说明。
- `backend/app/api/routes/vision.py`：问题、模型配置及错误码说明。
- `backend/app/services/vision.py`：回复和 token 用量字段的中文元信息。
- `tests/test_docs.py`：验证中文文档与资源可访问，以及原始字段合同保持一致。
- `README.md`：更新中文操作名称和说明。
- `prompts/P005_接口文档中文化.md`：本记录。
