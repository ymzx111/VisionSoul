# P001：VisionSoul 项目需求与规划记录

## 1. 基本信息

- 编号：P001
- 项目名称：VisionSoul
- 记录类型：项目需求分析与规划
- 日期：2026-11-07
- 阶段：项目初始化

## 2. 项目目标

开发一个具有视觉感知与动态人格模拟能力的多模态 AI 交互系统。

用户可以通过文字和图片与 AI 角色交流。AI 能够理解图片内容，并结合预设人格进行自然、连贯的对话。

## 3. 核心需求

1. 支持用户上传图片。
2. 能够理解图片中的场景、物体和细节。
3. 具有相对稳定的 AI 人格。
4. 根据对话情境调整模拟情绪和表达方式。
5. 能够保存部分用户经历和偏好，实现基础记忆。

## 4. 开发范围

第一阶段重点实现：

- 一个固定 AI 人格。
- 风景和日常图片理解。
- 文字聊天与图片上传。
- 人格化自然对话。
- 基础用户记忆。

暂不实现：

- 视频理解。
- 多角色系统。
- 语音交互。
- 复杂关系状态和主动事件系统。

## 5. 技术方案

- 前端：React + Tailwind CSS
- 后端：Python + FastAPI
- 数据库：SQLite
- AI：多模态大模型 API
- 版本管理：Git

## 6. 开发原则

1. 优先保证核心功能能够运行。
2. 采用模块化设计，方便后续扩展。
3. 每完成一个重要功能就进行测试。
4. 保存重要 Prompt 和 AI 修改记录。
5. 使用 Git 记录重要代码版本。
6. 不将 API 密钥等敏感信息提交到仓库。

## 7. 后续迭代方向

- 视频抽帧与理解。
- 多人格角色。
- 更完善的长期记忆。
- 语音交互。
- 情绪与关系状态模拟。
