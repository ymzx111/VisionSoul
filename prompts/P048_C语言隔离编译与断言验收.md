## 变更

- 新增 `tools/install_c_sandbox.py`：下载固定版本的 Zig 0.17.1（zip 95.7 MB），校验 SHA-256，去掉顶层目录按白名单解压（跳过 doc/），装到 `backend/storage/sandbox-runtime/c/zig-0.17.1`（实际占用 360 MB，gitignored）；压缩包缓存复用，改名失败时自动重试并退回复制。
- 新增 `backend/app/services/c_sandbox.py`：每轮独立临时目录里写 `main.c` / `main.cpp`，用固定路径的 zig 以固定参数编译成 wasm（C 用 `cc`、C++ 用 `c++`，目标 `-target wasm32-wasi -O1`），缓存目录用 `ZIG_LOCAL_CACHE_DIR` / `ZIG_GLOBAL_CACHE_DIR` 指到本轮临时目录并在多组用例间复用；产物交给 `c_wasi_worker` 在 Wasmtime 里运行。编译失败单独标记 `phase="compile"`，运行失败与输出不符沿用统一判定。
- 新增 `backend/app/services/c_wasi_worker.py`：只接受 WASI 导入，限量 192 MB 内存、燃料、4 秒 epoch 中断、16 KiB 输出上限，guest 目录只读，无网络与子进程。
- `python_sandbox.py`：把「多组用例逐组判定」抽成 `run_case_matrix`，Python 与 C/C++ 共用；`PythonCheck`/`CaseResult` 增加 `phase` 字段区分编译与运行。
- 接线：`local_ide.open_generated_source` 新增 `verify_c(code, language)` 回调，`.cpp/.cc/.cxx` 传 `cpp`、`.c` 传 `c`；聊天路由按语言分别调用 `debug_python` / `debug_c`。
- 语言范围：用户要求固定为 Python、C、C++，`source_files` 移除 C# 的扩展名与声明映射，错误提示改为“目前只支持 C、C++ 和 Python”。
- 配置：新增 `C_SANDBOX_ENABLED`、`C_SANDBOX_AUTO_REPAIR`、`C_SANDBOX_COMPILER`。
- 前端：验收样例面板对 C/C++ 同样生效，标题改为「沙箱验收」，结果按组显示。

## 验证

- 后端 244 项、前端 77 项通过；前端生产构建通过。
- 沙箱冒烟：三组断言（a→A、Q→q、5→5）在 C 与 C++ 下都全部通过；输出不符为 mismatch；少分号编译失败为 `phase=compile`；死循环为 limit。
- 实拍全链路（C）：同一段 C 语言实验视频留空提交 → 交付完整 C 源码 → 编译 → WASI 运行 → 3 组断言全过 → 保存 `workspace/C/2026.11.12.main-3.c` → 自动打开 Visual Studio。
- 实拍全链路（C++）：同一段视频要求用 C++ 交付 → `main.cpp` → 编译 → 3 组断言全过 → 保存 `workspace/C/2026.11.12.main.cpp` → 自动打开 Visual Studio。
- 语言范围：新增单测确认 `.py/.c/.cpp` 可解析，`.cs` 与未知语言被拒绝。
- 修复回环：编译错误整段回传（不含样例数据），运行失败或输出不符且带样例时只回传异常类型、行号与失败用例名；最多 3 轮，由单元测试覆盖（含“C++ 修复不接受 .c 文件”）。
