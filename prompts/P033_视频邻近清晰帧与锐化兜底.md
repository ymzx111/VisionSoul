# P033 视频邻近清晰帧与锐化兜底

2026-11-11。Codex 使用 PyAV 和 Pillow 完成本机处理，通过 Python unittest、Node test 与 Vite 验证。测试使用自制 H.264 题目片段和模拟模型。

> 先做第 3 种，用第 1 种给候选帧打分，第 2 种留作兜底。按照这个顺序，先针对视频分析模糊的问题进行代码改进。

- `video_details.py`、`video_refinement.py` 在一次隔离解码中读取高清候选的精确原帧和前后各半秒的局部候选。候选按约 0.125 秒分桶，有界保存。本地比较局部拉普拉斯方差、高频细节及颜色布局。用更细的局部比对区分运算符变化，重模糊时要求两侧清晰候选一致。仅轻度模糊且没有可信替代帧时生成独立锐化图。
- `videos.py`、`video_reading.py` 保存选帧来源和实际时间。请求标签、音画候选、排错和观察快照均按实际送入模型的图像计算。每次仍为一次模型请求，高清图最多 4 张。版本化的本机高清缓存区分原采样图和处理图。
- `api/routes/videos.py`、`VideoWorkspace.jsx`、`detail-selection.mjs`、`video-workflow.mjs` 以实际时间预览和回看，校验邻近帧、锐化帧的时间。旧报告缺少新字段时沿用原采样时间，旧版高清地址可读取原图。
- `test_video_refinement.py` 和 `detail-selection.test.mjs` 覆盖原采样模糊但邻近清晰、`<=` 与 `>=` 局部变化、重模糊两侧一致与冲突、轻度锐化兜底、截图回看和音画时间。真实解码测试确认接口截图字节等于送给模拟模型的图像。

后端 203 项、前端 74 项和生产构建通过。验证使用合成片段。局部阈值和内容相似度为首版启发式方法，实拍的运动拖影、压缩噪声和屏幕滚动仍需复测。模型用量为零，实际识别准确度和真实 API 用量留待用户原视频验证。
