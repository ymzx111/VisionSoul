# P051 填空类题目原样复现

- 日期 2026-11-12
- 工具 DeepSeek Harness（deepseek-flash）

## 实际请求

> 我发现一个问题：我视频提供的是填空题，里面有代码和注释，但是分析反馈给我的是纯代码的，能够让 ai 识别里面的题目，然后复现的项目里面也能够是“代码+注释”吗。同样在 py 编程里也要实现这个，接下来对这个进行优化一下。如果是代码题，就让它能够原模原样将题目复现下来，实现真的“进行填空”。

## 问题

- 填空题的题面自带代码骨架、注释和待填位置（例如 `//对输入ch进行判断，并进行字符转换`），但此前模型交付的是重写过的完整程序，原题注释和骨架丢失，用户没法对照原题核对"填了哪几处"。

## 变更

- `code_delivery.md` 新增填空/补全规则：题面已有代码骨架、注释提示或"//在此处填写"这类待填位置时，必须原样复现骨架——保留 include/import、变量声明、语句顺序、函数名、注释文字与待填标记，只在需要补的位置插入代码；不另写全新程序、不删改或合并原注释、不挪走待填注释；看不清的字符用 `？（画面不清）` 标注而不是猜成别的语句；补全后整份源码仍须能独立运行。该规则显式覆盖 C、C++ 和 Python，除非用户明确要求重写。
- 新增 `tests/test_code_delivery.py`：锁定提示词必须包含填空复现要求与三种语言的文件示例，避免以后被改回去。

## 验证

- 后端 249 项测试通过。
- 实拍全链路复测（实验3-4 大小写互换视频）：要求"补全题目里空着的部分，原样保留原有代码和注释"后，交付源码保留了题首注释、`char ch; scanf("%c",&ch);`、待填注释 `//对输入ch进行判断，并进行字符转换`，只在注释下方补 if/else；落盘 `workspace/C/2026.11.12.main-7.c`，沙箱编译运行、Visual Studio 打开均正常。
- Python 与 C++ 共用同一条交付提示词，规则一致；手上暂无 Python 填空素材，等有实拍素材再补一次同口径复测。
