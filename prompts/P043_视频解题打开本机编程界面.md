# P043 视频解题打开本机编程界面

2026-11-12。Codex 实现网页解题后自动保存源码和打开本机编程界面。

> 对的，分析好结果自动跳转出编程界面，把刚才任务要求的复制好，我只需要点击运行就能跑出结果了。我要实现的是这样的效果

- 工作解析视频话题要求完整程序时，提示模型在正常回复中提供固定文件声明和一个完整代码块。资料不足先追问，普通分析照常回复。首版接入 C、C++、Python。
- 网页从本机同源发起分析。成功保存聊天后，后端解析已保存的助手回复并校验语言、文件名和代码格式，每条回复保存到独立的 workspace 子目录。历史恢复、重复请求重放、角色空间、图片和文字话题不触发打开。
- C/C++ 使用本机 Visual Studio，生成可构建的 Win32 控制台项目和方案。Python 默认使用当前虚拟环境的 IDLE，可用 LOCAL_PYCHARM 配置 PyCharm。本机复用已打开的 PyCharm 窗口遇到 JetBrains 启动锁错误，实机选择 IDLE。Windows ShellExecute 只接收已配置 IDE 与已保存源码路径。
- 旧命令行脚本与网页共用源码提取和写入模块。独立保存目录及本机 IDE 路径不进入 Git。若编辑器启动失败，网页显示已保存路径供手动打开。
- 联调使用合成视频和模拟 DeepSeek 响应。通过本机窗口检查确认 C 源码与 Python 源码已出现在对应编辑器；用 VS2010 编译运行自制 C、C++ 示例并验证输出，用项目 Python 解释器验证自制 Python 示例输出。网页流程自动打开编辑器，运行由用户发起。
- 后端 221 项、前端 77 项测试及前端生产构建通过。完整模拟接口实测打开 visionsoul_ready.c 和 visionsoul_ready.py，已在对应窗口核对。预览服务已重启。
