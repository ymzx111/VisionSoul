# P053 实拍回归与编程验收优化

- 日期 2026-11-14
- 工具 Codex、本机 PyAV 与 Wasmtime、Zig、模拟 DeepSeek

## 实际请求

> 使用这两个实拍视频，对刚才四项建议进行优化。

## 实现

- 代码交付可附 1–3 组模型自测。手填样例和授权文件优先。模型自测单独标识，失败不追加模型修复。
- C/C++ 同轮只编译一次，独立沙箱分别执行各用例。暂不做跨请求持久缓存，Zig 仍在宿主机编译。
- 工作视频仅对可恢复的 JSON 根字段缺失或多余重取一次，证据、截断及冲突字段仍严格校验。格式重试和源码修复累计用量，修复请求只附结构化诊断，不带原始错误、输出、样例或用户命名。
- 新增 tools/regress_real_code_videos.py，用两段原始静音录像验证上传、抽帧、格式重试、落盘和沙箱。修复有非零视频起点的 Windows 录屏被误判解码不完整或音频处理失败。

## 实拍验证

- 3-3 三角形面积题。手算独立确认 3 组输出；真实运行通过，三组只调用一次 Zig。模拟缺少 observations 验证重取一次与用量累加；按原骨架核对落盘源码。
- 5-3 矩阵填空。原片只显示三行填空的代码骨架，目标矩阵缺失；回归固定回复应追问目标矩阵，不生成可执行源码。
- 两段均实测识别为静音。模型使用固定回复，未调用真实 API。IDE 启动在脚本中模拟。
